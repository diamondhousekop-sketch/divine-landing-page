# Divine Landing Page

Build a single, ultra-premium, highly realistic, conversion-optimized frontend-only 

landing page (React + Tailwind CSS, no backend/no forms functionality needed yet — 

static frontend with real content) for a spiritual e-commerce product called 

"इच्छापूर्ती लकी स्टोन" (Icchapurti Lucky Stone) by brand "Diamond House", Kolhapur.

═══════════════════════════════════════

DESIGN PHILOSOPHY

═══════════════════════════════════════

This must NOT look like a generic template. Think: premium temple-brand meets modern 

D2C e-commerce. Reference aesthetic quality level of brands like Isha Life, Kama Ayurveda, 

or a high-end Indian jewellery D2C site — but with devotional/astrology soul. It should 

feel expensive, trustworthy, and emotionally warm — like walking into a beautifully lit 

temple shop, not a flyer.

═══════════════════════════════════════

COLOR SYSTEM (exact hex)

═══════════════════════════════════════

- Background base: #FBF6EC (warm ivory, not pure white)

- Primary accent (deep maroon): #6E1423

- Secondary accent (temple gold): #C9962C with gradient to #E8C878 for shimmer effects

- Trust/CTA contrast: #1B2A4B (deep royal navy) — used ONLY for CTA buttons to create 

  strong contrast against warm palette

- Text primary: #2B1A12 (warm near-black)

- Divider/subtle lines: #E4D4B8

- Success/WhatsApp accent: #2FA84F (used sparingly)

═══════════════════════════════════════

TYPOGRAPHY

═══════════════════════════════════════

- Headings: "Playfair Display" or "Marcellus" (elegant serif, premium feel) paired with 

  a clean Devanagari font like "Tiro Devanagari Marathi" or "Baloo 2" for Marathi headlines

- Body: "Poppins" or "Inter" for English, "Noto Sans Devanagari" for Marathi body text

- Headline sizes: Hero H1 = 40-52px mobile / 64-72px desktop, bold, tight line-height (1.1)

- Use a gold underline/swash decorative element under key headlines (subtle, hand-drawn 

  style SVG accent)

═══════════════════════════════════════

IMAGERY DIRECTION

═══════════════════════════════════════

- Use REAL photography style (not cartoon illustrations) — warm-toned, golden-hour 

  lighting, temple/diya/incense smoke aesthetic in background textures

- Product shots: close-up macro photography style of the stone, on dark maroon velvet 

  with soft gold rim lighting (like premium jewellery photography)

- Human elements: warm, candid-style photos of Indian families, elders, devotional 

  settings — avoid stock-photo-stiff poses

- Background textures: very subtle temple mandala/arch line-art at 5-8% opacity, 

  soft bokeh diya-light glow effects behind key CTA sections

═══════════════════════════════════════

SECTION-BY-SECTION WITH REAL CONTENT

═══════════════════════════════════════

1. HERO SECTION

   - Full-bleed background: soft gold-glow gradient over ivory

   - Headline (Marathi, large, centered): "स्वामींचा आशीर्वाद, तुमच्या हातात"

   - Subheadline (English, smaller): "Kolhapur's Trusted Icchapurti Lucky Stone — 

     25+ Years of Genuine Blessings"

   - Video placeholder (rounded corners, gold border-glow, play button in center) — 

     16:9, autoplay-muted style mockup

   - Primary CTA button: navy (#1B2A4B) background, gold text, "आत्ताच मागवा" 

     (Order Now) with subtle pulse/glow animation on hover

   - Small trust row below CTA: 4 icons + text — "🏠 कोल्हापूर स्थित दुकान", 

     "✅ १००% असली", "🚚 सुरक्षित डिलिव्हरी", "📞 थेट संपर्क"

2. TRUST/AUTHORITY STRIP (sticky-feel band right under hero)

   - Dark navy background band, gold text

   - "श्री स्वामी समर्थ आशीर्वादित | महालक्ष्मी मंदिरामागे, जोतिबा रोड, कोल्हापूर"

   - Small verified badge icon style element

3. PROBLEM/EMOTIONAL HOOK SECTION

   - Section headline: "आयुष्यात या समस्या जाणवतायत का?"

   - 4-card grid (icon + short line each), warm card backgrounds with soft shadow:

     - "व्यवसायात अडथळे येतायत?"

     - "नोकरीत प्रगती थांबलीये?"

     - "लग्न किंवा नात्यात विलंब?"

     - "मनात सतत अस्वस्थता, अशांती?"

   - Note: keep health/legal framing emotional/spiritual (शांती, ऊर्जा), not medical/legal claims

4. SOLUTION / PRODUCT STORY SECTION

   - Split layout: product macro-photo on left (velvet+gold lighting), story text on right

   - Headline: "सिद्ध शुभरत्न — शास्त्रोक्त पद्धतीने सिद्ध केलेले खरे रत्न"

5. VIDEO TESTIMONIALS CAROUSEL

   - Horizontal scroll cards, each with video thumbnail (play icon overlay), gold 

     border frame, customer name + city placeholder ("राजू पाटील, कोल्हापूर"), 

     5-star rating in gold

   - Section headline: "आमच्या ग्राहकांचे अनुभव"

6. PRODUCT + PRICING BLOCK

   - Premium product gallery (3-4 angles), price displayed in large bold navy text 

     with a "special price" strikethrough-original-price pattern for urgency

   - "काय समाविष्ट आहे" checklist with gold checkmarks

   - Sticky bottom CTA bar (mobile) — price + "Buy Now" button always visible

7. FAQ ACCORDION

   - Headline: "सामान्य प्रश्न"

   - 5 real questions: असली आहे का?, रिफंड मिळेल का?, डिलिव्हरी किती दिवसात?, 

     कोणासाठी योग्य आहे?, पेमेंट सुरक्षित आहे का?

8. FOOTER / FINAL TRUST BLOCK

   - Shop address, phone number (96 57 130 131), Swami Samarth image small icon

   - "शुभरत्न न लाभल्यास किंवा इतर कोणत्याही कारणास्तव परत घेतले जाणार नाही" 

     — shown honestly but styled subtly, not alarming

═══════════════════════════════════════

CONVERSION PSYCHOLOGY TO APPLY

═══════════════════════════════════════

- Authority: temple/guru imagery + "25+ years" + physical address = credibility 

  against "scam" perception

- Social proof: video testimonials placed BEFORE price to build trust first

- Scarcity (honest): "मर्यादित स्टॉक — फक्त कोल्हापूर विभागासाठी" 

- Reciprocity/warmth: gentle, blessing-toned copy, not aggressive salesy tone

- Friction reduction: sticky CTA always visible on mobile, large tap targets (min 48px)

═══════════════════════════════════════

TECHNICAL/RESPONSIVE SPECS

═══════════════════════════════════════

- Mobile-first (375-428px primary), then tablet (768px) and desktop (1440px) breakpoints

- Smooth scroll-reveal animations (fade-up, 400ms ease) on each section entry

- Subtle gold shimmer/glow animation on CTA buttons (hover + idle pulse every 4s)

- Page load performance-conscious: lazy-load images below fold

- All Marathi text must render correctly with proper Devanagari font fallback stack
